# 胖叔 AI 入门老师

这是一个面向零基础用户的公开 Skill，目标是让学员通过自己的真实任务学会 AI：从基础认知、提需求和提示词，到资料核验、作品改进、工具/Skill 选择，再到 Vibe Coding 小应用。

当前版本：**v0.3.0 · 早期体验版**。适合刚接触 AI、不知道怎么提问，或已经尝试过 AI 但结果不理想的人。

## 这个 Skill 有什么作用？

它给支持 Skill 的 AI 助手提供一套中文教学方法和随包教材，让助手能解释、示范、带练和点评，帮助你逐步独立完成任务。

| 你遇到的问题 | 它可以怎样帮助你 |
|---|---|
| 不知道从哪里学 AI | 解释基础概念，围绕你的目标安排学习路线，从一个小任务开始 |
| 不会写提示词、说不清需求 | 把口语整理成目标、材料、输出形式和检查标准，给出可复制的表达 |
| AI 的回答不靠谱、文件好像没读到 | 检查实际材料，区分事实与推测，教你回查原文 |
| PPT 太丑、文案不合适 | 根据实际作品和用途诊断，给具体修改要求；有制作能力时按授权修改 |
| 软件卡住、报错看不懂 | 根据截图、报错和操作记录排查，说明怎么确认问题解决 |
| 同一个问题一直修不好 | 复查原因与执行条件，必要时整理交接卡，帮助换更适合的模型继续 |
| 不知道要不要装 Skill 或工具 | 判断能力缺口，核对候选工具，再指导安装、调用和验证 |
| 想做自己的小应用 | 帮你表达需求、整理简版 PRD，并学习运行、测试、保存与分享 |
| 看过教程，换个任务又不会 | 提供完整示范、相似练习和点评，用进度卡记录学习情况 |

随包包含 **8 个学习模块、48 个常见问题、文字/PPT/小应用等教学练习**。你可以直接解决眼前的问题，也可以系统学习；已有足够材料时会连续推进，不需要每一步都回复“继续”。

## 适合的问题

- 新手不知道该学哪些 AI 知识；
- 不会把需求、材料和验收标准交代给 AI；
- AI 做的 PPT、文案或应用效果不好，不知道问题在哪里；
- 不会操作、遇到报错或结果不对；
- 想知道什么时候使用模板、Skill、专用工具或更合适的模型；
- 想从 AI 基础一路学到 Vibe Coding。

## 设计来源

主体方法来自胖叔的 AI 入门课程与 WorkBuddy 课程知识整理；学习导航、统一入口和检查站机制参考 [xyskill](https://github.com/xyaz1313/xyskill) 的公开设计思路。本包不包含 xyskill 的原子库、脚本或云端检索服务。

## 使用方式

1. 选择 **Code → Download ZIP** 下载仓库，解压后将文件夹命名为 `pangshu-ai-beginner-coach`，其根目录直接包含 `SKILL.md`、`agents/` 和 `references/`。也可以下载仓库里的 `pangshu-ai-beginner-coach-v0.3.0.zip` 独立安装包；该包是 v0.3.0 发布快照，后续更新以仓库源文件为准。
2. 按你使用的 Agent 的安装说明，导入整个文件夹或放入它支持的 Skills 目录。保留 `SKILL.md`、`references/` 和 `agents/`，不要只复制一个文件。
3. 刷新技能列表或重新打开对话，明确调用这个 Skill，再用一个小任务检查效果。

Codex 中可显式提问：

```text
$pangshu-ai-beginner-coach 我完全不懂 AI。请用一个完整例子，教我把一段通知整理成待办清单，再解释怎么检查结果。
```

其他 Agent 是否支持安装、目录位置和调用语法，以该产品当前说明为准。本 Skill 不要求读取作者电脑、原始 PPT 或私人知识库。

安装后可以直接说：

> 我想学会用 AI 完成一件事，请从最简单的一步带我开始。

也可以直接提出具体问题，例如：

> 我刚才上传文件后出现这个提示，我想完成的是整理会议记录，请告诉我下一步怎么做。

更多可以直接问的问题：

```text
我不会写提示词，帮我把“做一份周报”这个需求说清楚。
这几页 PPT 看着很乱，请指出具体问题，教我怎么改。
这是报错截图，我刚才点击了运行，请帮我排查。
我想做一个待办清单应用，先帮我明确第一版的功能和验收标准。
我不想一直点下一步，先给完整示范，然后让我自己练一次。
```

## 老师的工作方式

- 只问概念：直接解释，不强制练习。
- 想解决任务：条件够用就连续推进到可检查结果。
- 想学会方法：完整示范、带练、点评，再换类似任务检查迁移。
- 作品不好：先诊断问题，再决定是否需要模板、Skill、专用工具或换模型。
- 遇到报错：截图问当前 Agent，保留复现事实和成功信号；相同办法连续失败两次就重新诊断。

Skill 资源按需读取，详见 `references/`。安装成功不等于宿主一定支持所有能力；请用实际任务验证是否加载和生效。

## 回答从哪里来？

回答由你使用的模型生成，结合当前可见材料、这份 Skill 的教学资源和模型通用知识；需要联网核实时，还取决于宿主是否提供联网能力。它不会自动查询胖叔电脑里的资料，也不能保证每句话都来自胖叔。详细依据见 [来源说明](references/sources.md)。

## 当前能力与验证范围

- 已完成本地目录同步、文件结构与引用检查，以及教学规则的独立审阅。
- 尚未完成多平台安装、多轮教学和真实截图排错的完整实测；不承诺任意聊天软件都能安装。
- 看图、读文件、生成 PPTX、运行代码和网页操作，取决于宿主工具与权限；安装 Skill 本身不会增加这些能力。
- Skill 面向免费学习分享，模型、API、宿主或部署服务可能另行收费。
- 使用虚构练习材料时会明确标注；学习进度卡需自行保留，不能默认跨对话永久记忆。

反馈时请说明所用 Agent、Skill 版本、实际提问、预期与实际结果；截图或日志先去掉密钥和私人信息。
