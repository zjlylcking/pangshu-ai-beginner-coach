# 起步与费用

这些是教学答法；具体软件操作使用时核验。按需结合用户事实，不逐条盘问。[依据说明](../sources.md)。

## F01｜我一点基础都没有，先学什么？〔P0〕

先学四件最能迁移到日常工作的事：知道 AI 能帮你做什么，把需求说清楚，给它合适的资料，以及检查和修改结果。之后再按任务进入写作、表格、PPT、资料问答或 Vibe Coding，不需要先背完整术语表。这是本 Skill 基于胖叔课程整理的学习范围，不是所有人都必须照着走的排名。

没有现成任务时，可以先用“一段通知整理成待办清单”做完整示范：看输入、写一句需求、得到结果，再回查原文有没有漏掉或编造。

下一步：说一件今天要做的事；若没有现成任务，就直接提供明确标为教学示例的短通知，不先让新手选一长串课程。成功信号：得到一份能逐项对照原文的结果。依据：L01、L03；教学设计。

## F02｜学 AI 一定要会编程、数学或英语吗？〔P1〕

日常使用 AI 不以这些技能为前提；做应用时需要逐步理解运行、输入输出、保存和测试，不能把“不手写代码”理解为“不用检查”。

下一步：先用中文完成一个资料整理任务。成功信号：能解释 AI 做了什么、自己核对了什么。依据：S02、S04、L01。

## F03｜工具太多，哪个最好？要都安装吗？〔P0〕

先看要完成什么、现有工具是否支持，不给永久排行榜。一次先用一个能完成当前任务的工具。

下一步：列出当前工具和目标结果，判断是否缺读取附件、看图、执行或导出能力。成功信号：选定一个入口并开始任务。依据：L01；选型设计。

## F04｜这个 Skill 免费，是不是用 AI 都不用花钱？〔P0〕

Skill 免费分享，模型、宿主软件、API 和部署服务可能各自有费用。聊天订阅是否包含 API 要看具体提供方，不能按一个品牌一概而论。

下一步：识别正在用的产品与收费入口，需要时查该产品官方计费页；未查到不报价格。成功信号：分清免费内容和可能收费的执行服务。依据：产品假设、L03；本轮未核验具体订阅/API 计费方案。

## F05｜手机能学吗？一定要买高配电脑吗？〔P1〕

聊天、表达需求和查看结果可按现有设备开始；运行本地项目或安装目录形式的 Skill 取决于工具和设备。先核实入口，再决定设备需求。

下一步：说明设备和正在用的应用。成功信号：找到可执行的小任务，或明确当前不支持的操作。依据：产品假设，不宣称任何手机端已兼容。
