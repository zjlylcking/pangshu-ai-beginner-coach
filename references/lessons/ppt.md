# PPT 质量改进课

以下为教学示例，不代表已处理用户原稿。需要工具扩展时先读 [工具引导](../tools/selection.md)。


### 输入与诊断

学员提供现有 PPT 或两三页截图、用途；若希望可编辑 PPTX，将其列为交付要求。已有信息足够就读取并判断，不逐项重新询问。

教学示例原页内容：

> 标题：项目情况。正文：本周完成产品说明整理、两个页面调整，客服反馈已经收集，宣传海报还没确定，下一周继续推进页面优化和活动准备。需要讨论海报方向，素材由设计同事补充。

示例问题：标题没有结论、已完成和待决策事项混在一起。这是对示例文字的判断；没有真实截图时不能声称发现了字体大小或配色问题。

### 改善示范

建议页结构：

- 标题：本周完成说明与页面调整，海报方向待确定。
- 已完成：产品说明整理；两个页面调整；客服反馈收集。
- 下一步：页面优化与活动准备；补充海报素材。
- 待决策：海报方向。

视觉要求：让待决策事项有明确层级，正文采用短项表达；配色和字号结合用途、展示设备与现有模板选择。不能为了“漂亮”加入没有来源的增长图表或完成率。

可复制修改要求：

```text
请基于现有内容改善这页汇报。
标题直接说明本页结论，把已完成、下一步和待决策分开。
保留原有事实，不增加业绩数字；文字保持可编辑。
先检查信息结构，再调整层级、对齐和留白。
处理后说明改了什么，并提供可打开的产物或当前工具能交付的替代形式。
```

### 工具分支

| 实际条件 | 老师行动 | 验证 |
|---|---|---|
| 现有宿主能编辑且方法足够 | 直接改善代表页，再按已明确方向推进 | 看实际页面和编辑状态 |
| 有合适的现成模板 | 核对可使用范围及格式后应用 | 没有内容溢出、结构匹配 |
| 缺专业制作方法且支持 Skill | 查真实候选，说明来源/依赖/费用/验证状态，获必要授权后安装调用 | 同样内容改善，不能只看安装日志 |
| 不能安装或不能生成 PPTX | 提供逐页内容与布局、可迁移指令，推荐可用制作入口 | 明确尚未生成或验证文件 |
| 安装后仍无改善 | 复查内容、参考、工具能力和调用是否生效 | 不把安装视为问题已解决 |

完成标准：内容准确、主结论清楚、层级可读、无溢出遮挡、用途匹配、交付格式正确；需要可编辑时抽查标题和正文能修改。没有取得原文件或没有编辑能力时，相应项目标未验证。

独立迁移：给第二页混乱材料，让学员自己写修改要求并指出最重要的验收项。不要只要求记住某个 Skill 的名字。
