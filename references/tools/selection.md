# 工具和 Skill 引导

先判断当前缺口：内容方法、视觉模板、文件生成、解析格式、外部访问还是模型能力。现有能力可通过具体反馈解决就直接做，基础教学不要求安装第三方 Skill。

用宿主实际有的搜索/仓库能力查真实候选；没联网就说明未核验，不编链接和安装命令，不暗中依赖未安装的 Find Skills 等工具。一次给一个主建议，必要时一个备选，说清解决哪部分、剩什么问题和成本。

## 工具卡字段

名称、官方/真实仓库、维护者；用途与不适用情形；宿主、系统、版本/修订；许可证；脚本/依赖、网络、数据流向、费用与权限；安装调用方式；停用/恢复方式；查验日期与验证状态；代表任务、实际结果、未验证项及替代方案。

状态分为：候选未审查、资料已核对、安装已验证、代表性任务已验证、过时/不可用。未知明确标未知；读 README 不等于安装测试，扫描也不能保证绝对安全。

## 推荐到使用

确定缺口 → 查真实候选并审查 → 给具体方案和成本 → 在授权内安装 → 显式调用 → 同任务/代表样本比较 → 保存调用方法。

只推荐不擅装；已明确授权具体方案则审查后推进，不反复确认。新增收费、上传或敏感权限未获授权时说明。保留同名既有内容的恢复方式，不覆盖未知修改。缺下载或执行能力时给核对过的步骤，等真实结果，不伪造已安装。

安装后验证发现/加载和实际产物；无改善重新诊断触发、输入、标准和工具能力，不继续盲目装更多工具。

| 卡点 | 先做 | 扩展与验收 |
|---|---|---|
| PPT 丑 | 结构、层级、参考与模板 | 制作 Skill/工具；渲染和编辑能力实测 |
| 文案空泛 | 真实材料、受众、具体修改 | 编辑方法；无新编事实、符合用途 |
| 表格不稳 | 字段、缺失、公式、样例 | 表格工具；合计、公式核对 |
| 应用出错 | 复现、范围、环境和改动 | 合适模型/调试工具；故障复验 |
| 重复工作 | 先跑通稳定方法 | 自建 Skill；换输入及失败处理测试 |

PPT 详见 [改进课](../lessons/ppt.md)。本包不预设通用已验证第三方推荐，需要依据接收者环境核验；某台机器已安装不代表所有人兼容。
